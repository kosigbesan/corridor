How the data actually reaches us

Most of it does not arrive by API.

Corporate travel emissions data usually lands as a scheduled CSV on an SFTP server, or a monthly report from a travel management company. The itinerary itself lives one layer down, in a GDS passenger name record. The connector strategy is three strategies stacked: reach the booking record, reach the HR record, and accept the file when neither is on offer.

02The gate is commercial

Every API here is documented and standards-based. The hard part is permission, not protocol.

Ingest
  • OAuth connectors for live feeds
  • SFTP and CSV watchers
  • Idempotent by booking id
  • Back off on HTTP 429
Reconstruct
  • Card line to itinerary
  • Great-circle distance, 8% uplift
  • Cabin from fare class
  • Haul band from distance
Quantify
  • DEFRA, ICAO, IATA factors
  • Radiative forcing, fixed basis
  • Tier tag, primary or secondary
  • Unit and factor version
Publish
  • One canonical ledger
  • CSRD, SB 253, CDP export
  • Assurance trail
  • Ledger API

Concur lets a client read its own data with a Client Web Services SKU and no certification, but a resold app in the App Center needs a signed Partner Agreement and a full certification project. Navan opens expense and user data but keeps bookings and webhooks behind partner access. Amex GBT requires an approved developer app. Amadeus closed its self-service portal on 17 July 2026, so GDS access now starts with a contract.

03Connector notes

What each connection takes

SAP Concur

OAuth 2.0, three data centers

Itinerary v4 is the Cat 6 feed, scope travelallowance.itinerary.read. The legacy ITINER scope still appears for older integrations.

Token care: the access token lasts one hour, the refresh token six months, and the base URI is geo-specific. Store the returned geolocation per customer or calls fail.

Two doors: client-owned data needs the Client Web Services SKU only. A multi-tenant App Center listing needs certification.

Amex GBT

Developer portal and certification host

OAuth 2.0 client credentials against the developer host, with a separate certification host for testing. The Get Trips API returns trips and their segments across air, hotel, car and rail.

Requires a registered account and an approved app. Egencia, the GBT brand, publishes thirteen public OpenAPI documents but gates the runtime, so contracts are readable before access is granted.

Navan

Self-serve credentials

The easiest starting point. An admin creates API credentials under Travel, Settings, Integrations, then hands over a client id and secret.

Token at /ta-auth/oauth/token, scopes bookings:read users:read. Bookings return under $.data[*], cursor paginated, with an includeTransactions flag for spend.

Limit: bookings and webhooks are gated to partner access, so a customer's own read is the realistic first step.

HRIS, the Cat 7 backbone

Workday, BambooHR, Personio, ADP

Workday exposes custom reports as a web service through RaaS, authenticated by an Integration System User with basic credentials or an OAuth token. BambooHR, Personio and ADP use API keys or OAuth, and ADP has a dedicated address API.

The only fields that matter: home location, work site, working pattern, and a mode plus distance from a survey. Everything else is payroll noise.

Data minimisation

Home address is personal data

A home postcode is personally identifiable. Corridor geocodes it to a distance band at ingest and discards the raw address, then aggregates commute reporting at five or more employees per cell. That is not only a privacy posture, it is what an assurer wants to see when the number is employee-derived.

04When no API is on offer

The fallback ladder, in order of fidelity

1

Live API, itinerary level

Booking feed gives distance, cabin and mode. Tier one, primary data. The target state.

2

Scheduled file extract

Monthly CSV from the TMC over SFTP, or the platform's own bulk export. Same fields, lower cadence. Still primary data.

3

Expense and card spend

Dollars, not kilometres. Applies EEIO factors and tags the record secondary. Enough to size the category, not to defend it.

4

Survey and national averages

For Cat 7 with no HRIS feed, a travel survey plus published commuting averages. Explicitly labelled as estimated.
